FOXY Clock

First setup: choose your time zone, your WiFi network and a web page password (Security section) below, then press Save.
This clock has no web page password. Set one in the Security section and press Save before making other changes: without it, anyone on your network could change the clock or install firmware.

Display

UP / DOWN on the clock adjust the level currently in use.

Sounds

Quiet hours do not affect alarms or button beeps. Chimes only sound once the clock knows the time. All clock sounds pause while an alarm rings.

Alarms

While a sounding alarm rings: UP or DOWN dismisses it, SET snoozes it. Alarms with sound off only drive GPIO14 and leave the buttons alone.

Security

After saving a new password your browser asks for it: any user name works, with the password you chose.

The clock has no HTTPS, so passwords cross your network unencrypted. The password keeps casual visitors out, not someone listening on your WiFi.

GPIO14

Current state: ?

3.3 V logic output on header J2 ("KEY"). It can drive a relay module or transistor input, not a load directly. It is undriven for about half a second at power-up (longer when buttons are held at power-on, and after a factory reset it comes up low), then goes straight to its saved level: fit a pull resistor on the connected device.
